# Portal Operacional · Rühling

Central interna de sistemas, ferramentas fiscais/contábeis e atalhos operacionais para a equipe da Rühling Inteligência em Contabilidade.

---

## 🛠️ Stack Tecnológica

* **Frontend:** HTML5, CSS3 (Custom Properties, Grid/Flexbox) e JavaScript Vanilla (ES6+).
* **Tipografia:** Google Fonts (*Montserrat* e *Open Sans*).
* **Infraestrutura:** Hospedagem estática com CI/CD integrado via **Vercel** e domínio customizado (`portal.ruhling.com.br`).

---
